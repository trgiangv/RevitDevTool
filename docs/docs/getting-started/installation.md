# Installation

1. Download the latest installer from [GitHub Releases](https://github.com/trgiangv/RevitDevTool/releases).
2. Install the package on Windows.
3. Start Revit or an AutoCAD-family host.
4. Open the RevitDevTool panel from the ribbon.

The supported host/year matrix is maintained in the repository README and release notes. Use the build configuration matching the Autodesk year when building from source.

## Build from source

The source repository requires the .NET SDK selected by `global.json`. See the repository [build and verification guidance](https://github.com/trgiangv/RevitDevTool/blob/develop/docs/agents/verification.md) for contributor-only instructions.
