# MEP workflows

RevitDevTool is infrastructure rather than an MEP application. Its value for MEP teams is enabling small, testable tools against real project context.

Examples include:

- connector and system validation;
- pipe and duct classification checks;
- parameter auditing;
- routing and clearance rules;
- geometry inspection and visualization.

The platform lets these workflows be built as ordinary Python, C#, F#, or test artifacts while retaining access to the live Autodesk model.
